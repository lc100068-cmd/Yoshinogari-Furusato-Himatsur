# 吉野ヶ里 ふるさと炎祭り 青年部お手伝いシフト

スマホで見られる、時間帯別のお手伝いシフト表です（1ファイル `himatsuri-shift.html`）。

- 公開ページ: https://claude.ai/artifact/JJBgrGJDaThYc4bUVVpikJ （共有設定はページの「共有」メニューから）
- 日程: 10/23（金）前日準備（竹切りなど 9:00〜昼過ぎ） / 10/24（土）1日目 終日 / 10/25（日）2日目 終日
  - 1日目・2日目の時間は仮で 9:00〜21:00 にしています。決まり次第「この日を編集」で直してください。

## 画面

| タブ | 内容 |
| --- | --- |
| 時間帯 | 30分ごとの「来られる人数 / 必要人数」と過不足（不足・未割当・OK）。行をタップすると名前と業務 |
| シフト | 日ごとの業務カード（時間・場所・必要人数・担当）。「LINE用にコピー」でグループに貼れる文章を作成 |
| メンバー | メンバーごとの来られる時間と担当（タイムライン表示） |
| わたし | 自分の名前を選ぶと、3日分の自分の担当だけを表示（端末に記憶） |

## 運営者の編集

編集権限のあるアカウントで開くと右上に「編集する」が出ます。

1. メンバー → 「＋ メンバーを追加」で名前と来られる時間（日ごとに複数の時間帯可、「終日」ボタンあり）
2. シフト → 「＋ 業務を追加」で業務名・時間・場所・必要人数。担当は「参加可 / 一部 / 時間外 / 重複」を見ながら選択
3. 下に出る「保存して共有」で全員の画面に反映

データはページ自体に保存されます（保存のたびに新しい版として公開）。
