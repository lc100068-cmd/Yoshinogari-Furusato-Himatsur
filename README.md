# 吉野ヶ里 ふるさと炎祭り 青年部お手伝いシフト

[公開ページ](https://lc100068-cmd.github.io/Yoshinogari-Furusato-Himatsur/)を開き、「入力」タブから参加できる時間を登録できます。Googleアカウントへのログインは不要です。登録後は「時間帯」「メンバー」「わたし」に反映されます。

## 参加者の入力方法

1. 「入力」タブで名前を入力する。
2. 10月23日・24日・25日ごとに「＋ 時間帯を追加」または「全時間」を選ぶ。時間帯は1日4件まで登録できる。
3. 「この内容で登録する」を押す。登録した名前と時間は公開シフト表に表示される。

同じ端末から再度開けば、登録内容を修正できます。修正に使う情報はブラウザー内に保存されます。ブラウザーのデータを消したり別の端末を使ったりすると、元の登録を上書きできません。その場合は運営者に連絡してください。

## 画面

| タブ | 内容 |
| --- | --- |
| 入力 | 参加できる時間の登録・修正 |
| 時間帯 | 30分ごとの来られる人数と必要人数 |
| シフト | 日ごとの業務・担当 |
| メンバー | 登録した人の参加可能時間 |
| わたし | 自分の予定の確認 |

日程は2026年10月23日（金）の前日準備、24日（土）・25日（日）の本番です。24日と25日の終了時刻は現在21:00の仮設定です。

## 運営者向け

参加者の入力はGoogle Apps Scriptの[保存処理](backend/Code.gs)に保存され、公開ページが読み込みます。Apps Scriptプロジェクト名は「吉野ヶ里ふるさと炎まつり・シフト入力」です。公開URLは `index.html` の `API_URL` に設定されています。登録を削除する際は、Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」で対象の `member:<id>` を削除できます。

業務・必要人数・担当の編集は参加者向け画面では扱いません。GitHub Pages版の初期データは `index.html` の `seed` に入っています。元の[Claude版](https://claude.ai/artifact/JJBgrGJDaThYc4bUVVpikJ)の変更はGitHub Pages版に自動反映されません。
